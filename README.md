# React on Express テストアプリケーション

このアプリケーションは、ReactフロントエンドとHonoベースのバックエンドを組み合わせたフルスタックプロジェクトです。TodoアプリケーションでのCRUD操作をデモンストレーションするために設計されています。

## フロントエンド

フロントエンドは、React、TypeScript、Viteを使用して構築されています。Viteを使用したReactの動作を最小限のセットアップで提供し、ホットモジュールリプレースメント（HMR）といくつかのESLintルールを含んでいます。

### 主な特徴

- **React + TypeScript**: 型安全性と最新のReact機能を保証します。
- **Vite**: モダンなWebプロジェクトのための高速なビルドツール。
- **ESLint**: ReactとTypeScriptの推奨ルールで構成されています。

### 開発

フロントエンド開発サーバーを開始するには:

```bash
cd apps/web
npm install
npm run dev
```

これにより、Vite開発サーバーが開始され、`http://localhost:3000`でアプリケーションにアクセスできます。

## バックエンド

バックエンドは、Honoを使用して構築されています。Honoは、APIを構築するための軽量なWebフレームワークです。

### 主な特徴

- **Honoフレームワーク**: シンプルで効率的なAPI構築を提供します。
- **CRUD操作**: Todoアプリケーションの作成、読み取り、更新、削除操作をサポートします。

### 開発

バックエンド開発サーバーを開始するには:

```bash
cd apps/api
bun install
bun run dev
```

これにより、バックエンドサーバーが開始され、`http://localhost:3000`でAPIにアクセスできます。

## アプリケーションの実行

1. **バックエンドを開始**: バックエンド開発手順に従ってサーバーを開始します。
2. **フロントエンドを開始**: フロントエンド開発手順に従ってViteサーバーを開始します。
3. **アプリケーションにアクセス**: ブラウザを開き、`http://localhost:3000`に移動してアプリケーションを表示します。

## 追加情報

- **ESLint構成**: フロントエンドには、プロダクションアプリケーション用に拡張可能なESLint構成が含まれています。
- **プラグイン**: React特有のLintルールのために追加のESLintプラグインを使用することを検討してください。
